# Stories → Publishing House

This playbook has grown into its own project and moved to a standalone repo:

**[publishing-house](https://github.com/gsarig/publishing-house)**: a publishing house in a vault. A clonable Obsidian vault wired for Claude Code with a complete fiction pipeline, from idea capture and story scaffolding through a staged editorial process (beta-reader personas, developmental/line/copy edits, proofread) to KDP-ready EPUB and paperback files.

The snapshot that used to live here was an early, much smaller version; use the repo instead.
